# v23 직업 이미지 매칭 수정

v22에서 생성된 `mercenary-jobs-v22.png`의 실제 배치 순서와 게임의 내부 무기 순서가 달라 일부 직업에 잘못된 이미지가 표시되는 문제가 있었습니다. v23에서는 아틀라스의 6×6 순서를 다음과 같이 직접 지정해 수정했습니다.

`모험가 → 검사 → 궁수 → 도적 → 마법사 → 사제 → 기사 → 광전사 → 사냥꾼 → 레인저 → 암살자 → 로그 → 원소술사 → 흑마법사 → 성직자 → 성전사 → 용기사 → 다크나이트 → 워로드 → 블러드마스터 → 비스트마스터 → 데드아이 → 윈드러너 → 스톰아처 → 나이트블레이드 → 쉐도우마스터 → 트릭스터 → 트레저헌터 → 아크메이지 → 엘리멘탈로드 → 네크로맨서 → 워록 → 세인트 → 오라클 → 팔라딘 → 인퀴지터`

이제 전투관전과 길드 내부에서 같은 직업은 같은 캐릭터 이미지와 무기를 사용합니다. 저장 버전은 23으로 올라가며 기존 저장 데이터는 유지됩니다.
