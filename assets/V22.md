# v22 직업별 전투 모션 및 길드 내부 이미지

## 직업별 캐릭터 모션

- `mercenary-jobs-v22.png` — 투명 6×6 아틀라스, 36개 직업 캐릭터
- 모험가부터 3차 전직까지 직업마다 다른 복장·무기·색감·실루엣을 사용합니다.
- 전투 중에는 직업별 캐릭터를 기준으로 준비·공격·회복 자세를 순환하고, 기존 직업 무기 오버레이와 타격·시전 이펙트를 동기화합니다.
- 기존 v20/v21의 역할 모션 시트는 보조 자산으로 남겨 구버전 저장과 폴백을 지원합니다.

## 길드 내부 이미지

- `guild-interior-v22.png` — 전투관전 화면과 같은 32-bit 픽셀 질감의 탑뷰 길드 내부
- 중앙 의뢰 게시판, 상단 훈련소·접수대·여관, 하단 주점·대장간·상점, 동쪽 출입구를 한 장면에 배치했습니다.
- 기존 실시간 이동 좌표와 클릭 선택은 유지하면서 이미지 위에 용병과 시설 상태를 표시합니다.

## 제작 프롬프트

직업 아틀라스는 36개 직업을 6×6 격자로 배치하고, 각 직업의 무기와 전투 실루엣을 다르게 지정했습니다. 길드 내부는 중앙 홀을 중심으로 훈련·접수·숙박·주점·대장간·상점·출입구가 연결된 탑뷰 구조로 지정해 전투관전 배경과 동일한 픽셀아트 톤을 사용했습니다.
