# 용병 길드

탑뷰 길드에서 용병들이 의뢰, 휴식, 훈련, 전직과 파티 활동을 자율적으로 수행하는 브라우저 경영 시뮬레이션입니다.

## 플레이

GitHub Pages 주소에 접속하면 별도 설치 없이 플레이할 수 있습니다. 진행 상황은 브라우저에 자동 저장되며, 저장 파일 내보내기와 불러오기도 지원합니다.

## 주요 기능

- 현실 1분 = 게임 1시간, 최대 5배속
- 00:00~06:00 자동 스킵 및 해당 시간의 진행 결과 계산
- 토벌·호위·채집·탐사·마법 의식을 보여주는 실시간 임무 관전
- 네임드 25종·배경 6종·직업 무기 20종의 전투 이미지
- 길드·시설·전투 화면에서 용병을 누르면 용병 상세로 이동
- 0차부터 3차까지 총 36개 직업
- 개인·파티·수집·네임드 의뢰
- 성격, 나이, 동료 관계와 고정파티
- 길드 시설 해금 및 강화
- 네임드 25종과 트로피 도감

## 실행

`index.html`과 `assets` 폴더를 함께 내려받고 `index.html`을 브라우저에서 열면 됩니다. 기존 저장 키를 유지하므로 같은 사이트·브라우저에서는 업데이트 후에도 이어서 플레이할 수 있습니다. 다른 브라우저나 로컬 파일로 옮길 때는 저장 내보내기/불러오기를 사용하세요.

이미지는 내장 imagegen 도구로 제작했습니다. [이미지 파일과 제작 프롬프트](assets/README.md)를 함께 제공합니다.
