# 용병 길드

탑뷰 길드에서 용병들이 의뢰, 휴식, 훈련, 전직과 파티 활동을 자율적으로 수행하는 브라우저 경영 시뮬레이션입니다.

## 플레이

GitHub Pages 주소에 접속하면 별도 설치 없이 플레이할 수 있습니다. 진행 상황은 브라우저에 자동 저장되며, 저장 파일 내보내기와 불러오기도 지원합니다.

## 주요 기능

- 현실 1분 = 게임 1시간, 최대 5배속
- 0차부터 3차까지 총 36개 직업
- 개인·파티·수집·네임드 의뢰
- 성격, 나이, 동료 관계와 고정파티
- 길드 시설 해금 및 강화
- 네임드 25종과 트로피 도감

## 실행

`index.html`을 브라우저에서 열면 됩니다.
